# 🚀 Quick Start Guide - MIDI Chord Import System

## Step 1: Install Dependencies
```bash
pip install mido numpy scipy scikit-learn
```

## Step 2: Launch the System
```python
from scripts.progression_rebuilder_gui import ProgressionRebuilderGUI

# Start the enhanced GUI with MIDI import capabilities
gui = ProgressionRebuilderGUI()
```

## Step 3: Import Your First MIDI File

1. **Open the MIDI Import Tab**: Look for the "🎵 MIDI Import" tab in the GUI
2. **Select Your MIDI Files**: 
   - Click "📁 Select Files" for individual files
   - Click "📁 Select Folder" for batch import
3. **Start Analysis**: Click "🎵 Analyze Selected"
4. **Review Results**: Check the "Analysis Results" tab for detected chords

## Step 4: Correct and Learn

When you see incorrect chord detections:
1. **Click on the wrong chord** in the results
2. **Select the correct chord** from the dropdown
3. **Click "Apply Correction"** - the system learns from this!

## Step 5: Watch It Improve

- **Each correction** makes the system smarter
- **More MIDI files** = better pattern recognition  
- **Check Statistics tab** to see improvement over time
